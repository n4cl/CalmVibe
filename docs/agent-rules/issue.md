# Issue ルール

## 参照タイミング
- Issue を作成・更新する直前に参照する

## 基本方針
- `.github/ISSUE_TEMPLATE/` から目的に合うテンプレートを選ぶ
  - 不具合報告: `bug_report.md`
  - 機能追加・改善提案: `feature_request.md`
- 本文はテンプレートの見出しをそのまま使う
- タイトルは prefix を付けず、変更対象や論点が先に分かる形にする
- Git 管理下の対象を中心に書く

## 補足
- タイトルに `feat:` や `fix:` などの prefix は付けない
- これは `.github/ISSUE_TEMPLATE/` のルールに従う
